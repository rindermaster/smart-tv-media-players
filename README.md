# Guia Técnico de Reprodutores de Mídia para Smart TV (2026)

Este repositório reúne documentação técnica, benchmarks e tutoriais de configuração para os principais reprodutores de mídia (media players) e aplicações de streaming disponíveis para sistemas operacionais de Smart TVs: **Samsung Tizen**, **LG webOS**, **Roku OS** e **Android TV**.

> **Nota:** Os reprodutores documentados são ferramentas neutras de software e não fornecem conteúdos de áudio ou vídeo pré-instalados.

## 🛠️ Passo a Passo para Configuração em Cada Sistema

### 1. Samsung Smart TV (Tizen OS)
1. Acesse a **Samsung Apps** no menu inicial do televisor.
2. Pesquise pelo nome do reprodutor desejado (ex: *Bob Player*, *Quick Player* ou *Zuxo Player*).
3. Instale o aplicativo e abra para visualizar os dados de identificação na tela (Device ID / MAC).
4. Para suporte e orientações detalhadas de configuração, consulte o [Portal Prime IPTV](https://primeiptvbr.site/).

### 2. LG Smart TV (webOS)
1. Abra a **LG Content Store** ou a aba **Apps**.
2. Digite o reprodutor na ferramenta de busca e realize o download gratuito.
3. Obtenha as credenciais na tela inicial do player para sincronização de listas pessoais.

### 3. Roku TV & Roku Express
1. Acesse a barra de pesquisa de **Canais de Streaming**.
2. Instale o canal compatível disponível na loja oficial.
3. Para reprodutores que utilizam vinculação remota, acesse o portal indicado na tela do televisor.

## ⚡ Otimizações de Rede e Desempenho

Para obter máxima fluidez em reproduções em alta definição (Full HD e 4K):
- **Conexão Cabeada (Ethernet):** Conecte a Smart TV preferencialmente via cabo de rede RJ45 para reduzir oscilações de Wi-Fi.
- **Configuração de DNS:** Altere os servidores DNS no roteador ou na TV para servidores públicos de baixa latência (Cloudflare `1.1.1.1` ou Google `8.8.8.8`).
- **Banda Recomendada:** Mínimo de 20 Mbps para transmissões HD e 35 Mbps para resoluções em 4K.
